# Network Intrusion Detection System Frontend

A React app for predicting network intrusions using a machine learning model.

## Setup

1. Install dependencies: `npm install`
2. Start the development server: `npm start`
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Usage

- Enter the feature list in JSON format.
- Click "Predict" to get the result.

## Backend

Ensure the Flask API is running and update the `API_URL` in `src/App.js` with the correct ngrok URL.

## Build

Run `npm run build` to create a production build.
